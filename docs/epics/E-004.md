# E-004: Admin Dashboard — Phase 1 Data Review & Management

Project: Pando
Status: approved
Priority: must

Provide the Pando admin team with a dashboard to review, approve, reject, and annotate contributor submissions without requiring direct database access. This epic also covers caregiver consent workflow management and pending taxonomy option promotion.

## Acceptance Criteria

• Admin can view all contributor records with completion status, profile completeness score, and submission count
• Admin can approve or reject individual activity recommendations with notes
• Admin can view all caregiver nominations and manage consent_status transitions (pending → consented or declined)
• Admin can annotate any record with internal notes
• Admin can review and promote 'Other' taxonomy entries to the canonical list
• Admin dashboard requires authenticated login; each action is attributable to a named admin user
• Dashboard provides funnel visibility into drop-off points across the onboarding flow
• Admin can confirm data quality is sufficient before Phase 2 launch
• At least one caregiver record can be fully activated (consent_status = consented AND active = true) through the dashboard
