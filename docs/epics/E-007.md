# E-007: Thanks Loop & Contributor Engagement System

Project: Pando
Status: approved
Priority: must

Close the feedback cycle between querying parents and contributing community members by prompting parents to send thanks after a recommendation is acted upon, routing thanks back to contributors, and progressing contributors through engagement tiers. This epic is essential to sustaining contributor participation through the pilot period.

## Acceptance Criteria

• Pando prompts the querying parent a configurable number of days after a resolved query to ask if the recommendation worked out
• Parent can respond Y/N to trigger a thanks event (thanks_given = true/false)
• Thanks messages are batched to contributors — no more than one per contributor per week
• Contributors receive a thanks message when at least one parent attributes a positive outcome to their contribution
• Contributor tier status is updated based on quality response count, thanks received, and response rate
• Tier progression is stored per contributor_id and visible in the admin dashboard
• Thanks delivery rate is measurable (thanks_events with thanks_given = true / resolved queries)
• Contributor opt-out rate is tracked; contributors can opt out of Blasts without losing their profile or recommendation data
• The thanks loop operates without manual intervention from the admin team
