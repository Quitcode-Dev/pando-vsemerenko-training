# E-006: Blast System — Outreach, Fulfillment & Payment

Project: Pando
Status: approved
Priority: must

Deliver the paid Blast mechanism that allows querying parents to purchase targeted community outreach across Standard, Targeted, Precision, and Last Minute Care tiers. This epic covers contributor scoring and selection, frequency cap and gap rule enforcement, Stripe payment integration, admin fulfillment workflow, and answer delivery within the promised time window.

## Acceptance Criteria

• Four Blast tiers are supported: Standard, Targeted, Precision, Last Minute Care
• Parents are presented with a Stripe payment link and must confirm payment before a Blast is activated
• Blast contributor pool is scored using two-layer matching (social affinity + life relevance)
• Frequency caps and the 48-hour gap rule are enforced in code with no manual overrides required
• Each contributor's blast_opt_in status is respected; opted-out contributors are never contacted
• Contributors receive a warm, low-friction SMS Blast message
• Admin can review contributor responses and approve the best answer for delivery
• Approved answers are delivered to the querying parent within the tier's promised time window
• Payment events are captured via Stripe webhooks and stored per conversation
• Blast response rate per contributor is tracked over rolling 30 days
• Refund flagging is available to admin for failed or undelivered Blasts
