# E-001: Contributor Access & Identity Management

Project: Pando
Status: approved
Priority: must

Establish the mechanism by which founding contributors access the Seed Tool without an app download or account creation. This epic covers invite link generation, phone number capture, and contributor record creation to ensure every submission is attributed to a unique, trackable identity.

## Acceptance Criteria

• Seed Tool is accessible via mobile browser URL with no app download required
• Each contributor can access the tool without a username or password
• Unique invite links are generated per contributor and associated with a specific contributor record
• Phone number is captured in E.164 format and used as contributor identity
• Contributor record is created upon access with a unique contributor_id
• Access links render correctly on iOS Safari and Android Chrome at mobile viewport sizes
• Completion status is trackable per invite link
• Duplicate or reused link access is handled gracefully
