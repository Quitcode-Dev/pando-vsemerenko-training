# E-003: Structured Recommendation & Caregiver Nomination Ingestion

Project: Pando
Status: approved
Priority: must

Enable founding contributors to submit structured activity recommendations and caregiver nominations through a conversational seed flow. This epic captures all recommendation data including freshness signals, caveats, and reference willingness, and flags caregiver nominations for separate human-managed consent outreach.

## Acceptance Criteria

• Contributors can submit one or more activity recommendations per session
• Each recommendation captures: activity name, description, caveats, freshness date, and contributor attribution
• Contributors can nominate caregivers by first name and last initial only
• Caregiver nominations are flagged with consent_status = pending and never activated automatically
• No caregiver nomination is surfaced to any querying parent without consent_status = consented AND active = true
• Recommendation flow feels conversational, not form-like
• Contributors can submit at least 2 recommendations in a single session
• Blast opt-in preference is captured during onboarding
• All submitted data is stored in structured form linked to contributor_id
• Contributors can return to add more recommendations (if confirmed by Pando team)
