# US-008: Pending Taxonomy Option Review

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: M

**As a** Pando admin
**I want** to review free-text 'Other' entries submitted by contributors across all questionnaire fields
**So that** I can promote commonly used values into the canonical options list and improve matching quality over time

## Acceptance Criteria

- All 'Other' free-text entries are saved to a pending taxonomy table with: field name, submitted value, contributor ID, and submission date
- The admin dashboard has a dedicated 'Pending Taxonomy' section listing all unreviewed 'Other' entries grouped by field
- Admin can mark an entry as 'Promote to canonical' (adds the value to the selectable options for that field) or 'Dismiss' (no action taken)
- Promoting a value to canonical makes it immediately available as a tap option for that field for any contributor who has not yet completed that section
- Dismissed entries are retained in the pending taxonomy table with status = 'dismissed' and do not reappear in the review queue
- Duplicate submitted values for the same field are de-duplicated in the review view and show a count of how many contributors submitted that value
- Promoting a canonical value does not retroactively alter any existing contributor records that used the free-text version
