# US-001: Invite Link Access for Founding Contributors

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: M

**As a** founding contributor
**I want** to open a unique invite link on my phone and access the Seed Tool immediately
**So that** I can participate without downloading an app or creating a password-based account

## Acceptance Criteria

- The Seed Tool URL opens in a mobile browser (iOS Safari and Android Chrome) without prompting an app download
- Each invite link is unique and tied to a specific contributor record in the database
- A contributor can complete the full onboarding flow using only the invite link — no username or password required
- Accessing the link marks the contributor record with an 'accessed' timestamp
- An already-used link that has been completed still loads the tool and does not show an error to the contributor
- An invalid or expired link displays a clear, friendly error message rather than a blank or broken page
- The invite link page renders correctly at 375px and 390px viewport widths
