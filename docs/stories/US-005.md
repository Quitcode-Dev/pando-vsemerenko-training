# US-005: Admin Dashboard — Submission Review and Approval

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: L

**As a** Pando admin
**I want** to review, approve, or reject contributor-submitted activity recommendations and caregiver nominations from a dashboard
**So that** only verified, quality-checked records are used in Phase 2 answers without requiring direct database access

## Acceptance Criteria

- The admin dashboard displays all submissions with status 'pending' in a prioritised queue
- Each submission shows: contributor name, submission date, full recommendation or nomination details, and current status
- Admin can approve a submission (sets status = 'approved'), reject it (sets status = 'rejected'), or flag it for follow-up (sets status = 'flagged')
- Admin can add a free-text internal note to any submission record; notes are timestamped and attributed to the admin user who wrote them
- Approved activity records become immediately eligible for Phase 2 answer retrieval
- Rejected records are retained in the database with status = 'rejected' and are never surfaced in answers
- The dashboard shows aggregate counts: total pending, total approved, total rejected, total caregivers awaiting consent outreach
- All admin actions are logged with a timestamp and the admin user's identifier for auditability
- The dashboard is accessible only to authenticated admin users and is not reachable via the contributor invite link flow
