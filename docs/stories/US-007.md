# US-007: Blast Opt-In During Contributor Onboarding

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: S

**As a** founding contributor
**I want** to opt in to receiving Blast SMS requests during the onboarding flow
**So that** I can be included in the Phase 2 Blast respondent pool and contribute knowledge when parents have urgent needs

## Acceptance Criteria

- A clearly worded opt-in prompt is presented to every contributor before the end of the onboarding flow
- The opt-in prompt explains what Blasts are (occasional SMS requests from parents seeking recommendations) before asking for consent
- Selecting 'Yes' sets blast_opt_in = true on the contributor record; selecting 'No' or skipping sets blast_opt_in = false
- The opt-in step is skippable — declining does not prevent the contributor from completing the rest of onboarding
- blast_opt_in status is displayed on the contributor record in the admin dashboard
- Admin can manually update blast_opt_in on any contributor record and the change is logged
- Contributors who have not provided a phone number in E.164 format cannot have blast_opt_in = true, and the system surfaces a validation error if admin attempts this
