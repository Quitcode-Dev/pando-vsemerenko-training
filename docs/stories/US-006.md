# US-006: Caregiver Consent Status Management

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: S

**As a** Pando admin
**I want** to update a caregiver's consent status to 'consented' and set active = true after completing manual consent outreach
**So that** only caregivers who have explicitly agreed appear in user-facing answers

## Acceptance Criteria

- Admin can update consent_status from 'pending' to 'consented' or 'declined' on any caregiver record
- Setting consent_status = 'consented' does not automatically set active = true; admin must explicitly toggle active = true as a separate step
- A caregiver with consent_status = 'declined' cannot be set to active = true; the active toggle is disabled for declined records
- Updating consent status is logged with the admin user's identifier and a timestamp
- The admin dashboard displays a count of caregivers in each consent state: pending, consented-active, consented-inactive, declined
- Admin can deactivate a previously consented caregiver (set active = false) without changing consent_status
- A caregiver record shows the full audit trail of status changes in the admin detail view
