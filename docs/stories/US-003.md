# US-003: Conversational Activity Recommendation Submission

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: L

**As a** founding contributor
**I want** to share activity recommendations through a conversational, chat-like interface
**So that** contributing knowledge feels natural and low-effort rather than like filling out a form

## Acceptance Criteria

- The recommendation interface presents prompts sequentially in a chat-bubble style, not as a multi-field form
- Each activity recommendation captures at minimum: activity name, category, age range, and the contributor's personal endorsement note
- Optional fields (budget range, schedule, location/neighborhood) are presented as tap selections after the required fields are complete
- A contributor can submit more than one activity recommendation in a single session without restarting the flow
- Each submitted recommendation is saved to the database linked to the contributor's unique ID
- A submitted recommendation receives a default status of 'pending' until reviewed by an admin
- The contributor sees a confirmation message after each recommendation is saved
- Partial entries that are abandoned mid-flow are not saved as complete recommendations
