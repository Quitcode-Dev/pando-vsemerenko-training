# US-004: Caregiver Nomination Submission

Project: Pando
Epic: Unassigned
Status: approved
Priority: must
Effort: M

**As a** founding contributor
**I want** to nominate a caregiver by providing their first name, last initial, and my relationship to them
**So that** the Pando team can follow up for consent before the caregiver appears in any user-facing answer

## Acceptance Criteria

- The caregiver nomination form collects: first name, last initial, relationship type (e.g., our nanny, neighbour's sitter), and an optional endorsement note
- Full last name is not collected at the nomination stage
- Every submitted caregiver nomination is saved with consent_status = 'pending' and active = false by default
- No caregiver record with consent_status != 'consented' OR active != true can be returned by any answer retrieval query
- The contributor sees a clear message after submission stating that the caregiver will be contacted separately before appearing in results
- A contributor can nominate more than one caregiver per session
- Caregiver nominations are visible in the admin dashboard with a 'Pending Consent Outreach' label
- The system does not send any automated communication to the nominated caregiver — consent outreach is handled manually by the Pando team
